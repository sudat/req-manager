# DD管理画面 UI/UX改善

## 作業概要

DD（Design Document）編集画面のUI/UXを改善する。
プログレッシブカード方式を採用し、入力の意思（クリック）があるまでセクションを展開しない設計とする。

## 設計方針

- **プログレッシブディスクロージャー**: クリックで展開
- **視認性とミニマリズムのバランス**: スレート系で統一
- **必要十分な入力欄**: フォーカスで拡張
- **必須バッジ**: 控えめなグレー表記
