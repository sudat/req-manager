# SNS戦略ドキュメント更新計画：マネージドスクラッチモデルへの整合

## Context

ビジネスモデルが「請負開発（買い切り）」から「マネージドスクラッチ（月額サブスク・解約自由・初期費用ゼロ）」に転換された。BusinessModel_ManagedScratch.md と OperationModel_ManagedScratch.md は新モデルで定義済みだが、SNS戦略3ファイルは旧モデル（プロジェクトベース課金）前提のまま残っている。これらを新モデルに整合させる。

## 変更の核心

| 旧モデル（請負開発） | 新モデル（マネージドスクラッチ） |
|---|---|
| 初期費用あり（診断50-100万、プロトタイプ100-300万） | 初期費用ゼロ、月額課金のみ |
| 買い切り・納品 | 解約自由・システム回収 |
| 「バリューベース価格」「効果の10-20%」 | 月額2万円/機能（概算）、段階課金 |
| 保守月額5-8万円（別契約） | 保守込みの月額（安定稼働後は半額） |
| リスクはクライアント側 | リスクは須田側（クライアントは解約可能） |
| 準委任契約 | サービス利用契約 |

## 変更しないもの

- ポジショニング「パッケージのスキマ専門家」: そのまま有効。マネージドスクラッチはこのポジショニングの「提供形態」が変わっただけ
- コアメッセージの骨格: 「課題構造を描写し、打ち手の輪郭を見せる」は変わらない
- 投稿ジャンルのA-F, H, I, K, L, M, N, O, P, Q群: 業界批判・技術・キャリア系は提供形態に依存しないため変更不要
- タイムライン（4年ロードマップ）: フェーズ構成は変わらない

## 実装順序

1. **SNS_Strategy_note.md** を最初に更新（テーマ⑧⑰のリライトが最も重要。他ファイルからの参照あり）

## 検証方法

- 各ファイル更新後、BusinessModel_ManagedScratch.md と OperationModel_ManagedScratch.md の数値・用語と矛盾がないか突合
- 3ファイル間で価格表現・ポジショニング・CTAが一貫しているか確認
- 旧モデルの表現（「納品」「買い切り」「診断50-100万円」「プロトタイプ100-300万円」「保守月額5-8万円」「準委任契約」等）が残っていないか全文検索
